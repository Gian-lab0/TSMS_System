# Publish TSMS online (Render)

I cannot create the public URL from this chat because the hosting account and deployment must be created/authorized by you. This folder is prepared for Render.

## Before deployment
- Make sure this project is in a Git repository you control.
- Do not upload real teacher/student data until your school approves the hosting and privacy setup.
- This configuration uses a persistent disk (`starter` plan) for the SQLite database. If the host asks you to choose a plan, choose one that supports persistent disks. A free/ephemeral instance may lose database changes.

## Steps
1. Create/sign in to your Render account.
2. Push this project folder's contents to a private GitHub repository.
3. In Render, choose **New + → Blueprint** and connect that repository.
4. Render will read `render.yaml`. Confirm the service and persistent disk settings.
5. When asked for `ADMIN_EMAIL`, enter the email address that should be the administrator. Register that account after deployment if the database is new.
6. Deploy. Wait until the service is live. Render will show a URL like `https://your-service-name.onrender.com`. The actual URL is generated by Render and cannot be predicted in advance.
7. Open that HTTPS URL on your phone and other computers. All devices use the same hosted website and database.

## Important
- Keep the GitHub repository private. Never commit passwords, secret keys, or school data.
- Keep `TSMS_SECRET_KEY` private; Render generates it from the Blueprint configuration.
- Back up the database regularly.
- Before production use, add CSRF protection, secure cookie settings, and verified account recovery.
- If `ADMIN_EMAIL` is set, it should match the admin's registered email. Confirm the app's admin-role setup before sharing the URL.
